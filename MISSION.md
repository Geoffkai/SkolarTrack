# Mission: Building SkolarTrack (Full-Stack Web Dev)

## Why
Geoffrey is a CS student in Quezon City building 3 portfolio projects to land a junior full-stack developer role in the Philippines (₱35k–₱55k/month range). SkolarTrack is Project 1 — a real scholarship aggregator for Filipino students, not a tutorial toy. The goal is a deployed, interview-ready project that demonstrates auth, RBAC, REST APIs, PostgreSQL, and React.

## Success looks like
- A live URL (Railway + Vercel) that anyone can visit and use
- A confident "walk me through your project" answer in a job interview
- Full understanding of every line of code — no copy-pasting without knowing why
- All 8 pages functional, JWT auth working, role-based access enforced
- Database queries in models, never in controllers — clean architecture throughout

## Constraints
- Built during vacation (5–6 hours/day), target 2 weeks
- No local PostgreSQL — Neon.tech only
- Prior knowledge: Java, SQL, HTML/CSS/JS — strong foundation, first real full-stack web project
- Goal is employability in the PH market (React + Node.js focus)

## Out of scope
- Email notifications, file uploads, real-time features — v2 concerns
- Laravel/PHP — learn after this 3-project pipeline
- TypeScript — keep it JS for now, add TS in Project 2 or 3
